プライバシーポリシー

最終更新日:2026年10月13日

1. 対象

本ポリシーは、個人用ツール「yt-auto」(以下「本ツール」)に適用されます。本ツールの利用者は運営者本人のみです。

2. 取得する情報

本ツールは、Google の OAuth 認証を通じて、運営者自身の YouTube チャンネルに動画をアップロードする権限 (YouTube Data API の youtube.upload および youtube スコープ)のみを取得します。

3. 利用目的

取得した権限は、運営者が作成した動画・サムネイル・説明文を運営者自身のチャンネルへアップロードし、 公開日時を設定するためだけに使用します。

4. 第三者への提供・共有

取得した情報を第三者に販売・提供・共有することはありません。第三者の Google アカウントのデータにはアクセスしません。

5. 保存と削除

認証情報(リフレッシュトークン)は、運営者のみがアクセスできる暗号化されたシークレット領域に保存します。 権限は Google アカウントの「サードパーティのアクセス」設定からいつでも取り消せます。

6. Google API サービスのユーザーデータポリシー

本ツールによる Google API から取得した情報の利用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。 また、本ツールは YouTube API サービスを利用しており、YouTube 利用規約および Google プライバシーポリシーが適用されます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub の運営者ページ(github.com/b252007-prog)からご連絡ください。
